The API reference of the uiconfig packages: the config types and decorators, and the two renderers. Pick a package
here or in the switcher at the top of each page; the search covers all three.

- {@link "uiconfig.js"! | uiconfig.js}: the config types (`UiObjectConfig`), the decorators (`uiSlider`, `uiContainer`, …),
  `generateUiFolder`, and the base classes of renderers.
- {@link "uiconfig-tweakpane"! | uiconfig-tweakpane}: the renderer on Tweakpane, with `setTheme` and the theme modes of
  `uiconfig-tweakpane/theme.css`.
- {@link "uiconfig-blueprint"! | uiconfig-blueprint}: the renderer on Blueprint (React).
