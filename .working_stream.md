# Working stream — `uiconfig-dom` (draft)

## Summary

- **What:** a new package, `uiconfig-dom`: a plain-DOM renderer for uiconfig.js configs, with no Tweakpane and no React.
- **Why:** every renderer in this repo needs a UI library. `uiconfig-tweakpane` needs Tweakpane. `uiconfig-blueprint`, `uiconfig-react` and `uiconfig-shadcn` need React. Small places, such as a popup or a card next to a 3D object, need a light form.
- **Where it starts:** threepipe `UiConfigForm`, in `plugins/tweakpane-editor/src/UiConfigForm.ts`, from https://github.com/repalash/threepipe/pull/90. It is about 24 KB of source and adds no dependencies.
  - **Fields:** number (drag the label, Shift for 10×), slider, checkbox, dropdown, vector, color, text, button, monitor, and folders (always open).
  - **Changes and undo:** it calls `onChange` on the field and on its parent folders. With an undo manager, each edit is one undo step, and quick edits of one field merge into one step.
- **Decided (2026-10-30, threepipe #90):** UiConfigForm stays in `@threepipe/plugin-tweakpane-editor` for now. It moves here only when a user outside threepipe needs it. This draft PR is the reminder for that move, at the user's request on 2026-11-03: "make draft pr in that for later and link to this. so we dont forget it."
- **Status:** not started. This branch has only this file. Nothing is deployed.
- **Blocked on:** a user outside threepipe who needs it, or a decision by Palash to do it earlier.

## The plan (when we do it)

1. **Many refresh listeners:** a config has one `uiRef` and one `uiRefresh` slot, and the Tweakpane panel already uses them for the same configs. So uiconfig.js must allow more than one refresh listener for each config. Then a form and a panel can show the same config, and `config.uiRefresh()` updates both. Today the form needs a manual `refresh()`.
2. **One base class:** the renderer extends `UiConfigRendererBase` and uses its `methods` (`setValue`, `PerformAction`, the disabled check), not its own copies.
3. **No threepipe imports:** the threepipe imports in UiConfigForm are re-exports of uiconfig.js and ts-browser-helpers, so replace them with direct imports. The `--tp-*` colours are only fallbacks, so rename them to `--ucf-*`, or keep both names.
4. **Missing aliases:** handle the `select` and `vector` aliases, which fall back to plain fields now.
5. **Package:** add `packages/uiconfig-dom` (README, CHANGELOG, LICENSE, a vite build like `uiconfig.js`) and a website page.
6. **threepipe:** re-export it from `@threepipe/plugin-tweakpane-editor` under the same name `UiConfigForm`, so code that uses it keeps working.
